# نظام إدارة مستشفى لجنة زكاة ميت على التخصصي

نظام إدارة طبي وإداري ومالي شامل مبني بنمط **Web App / PWA** احترافي باسم:
**نظام إدارة مستشفى لجنة زكاة ميت على التخصصي**.

## الهيكلية التقنية

- **الواجهة الأمامية**: HTML5 / CSS3 / JavaScript حديث، متجاوب تمامًا مع شاشات الكمبيوتر والأجهزة اللوحية والهواتف الذكية.
- **تطبيق تقدمي (PWA)**: يدعم التثبيت المباشر على الأجهزة عبر `manifest.webmanifest` وService Worker (`sw.js`).
- **قاعدة البيانات والسحابة**: **Supabase (PostgreSQL 16+)** بجداول علائقية صريحة مخصصة لكل قسم (`visits_*`, `income`, `expense`, `payroll`, `doctors`, `employees`, `patient_file_index_*`)، مع سياسات أمان مشددة (Row-Level Security) وتقييد صلاحيات الاستعلام.
- **التخزين المحلي والعمل دون اتصال**: IndexedDB للكاش المحلي وقوائم الانتظار الذكية مع دعم مزامنة تلقائية فور عودة الاتصال دون تكرار للبيانات أو كسر لفلاتر الصفحات.
- **الخادم والواجهات الخلفية**: دوال خادمية (Vercel Serverless Functions) في مجلد `api/` للعمليات المحمية والإحصائيات المالية وإدارة الحسابات.

## أقسام النظام

- **يوميات العيادات التخصصية**: عيادات الباطنة، الأطفال، العظام، الجراحة، النساء والتوليد، الرمد، إلخ.
- **يومية عيادة الأسنان**: سجل الزيارات، التشخيص، الإجراءات، المبالغ المستحقة والمدفوعة.
- **يومية العمليات الجراحية**: إدارة العمليات، الأطباء المشاركون، رسوم العمليات.
- **يومية التحاليل المخبرية**: فحص وتحديد أسعار التحاليل ومصاريف المعمل.
- **يومية الأشعة**: الأشعة العادية، المقطعية، الرنين، السونار، الدوبلر، البانوراما.
- **فهارس ملفات المرضى وتاريخ الزيارات**: فهرسة تلقائية مبنية على زيارات المريض الفعلية مع مطابقة الأرصدة.
- **المالية والخزينة**: تسجيل الوارد، المنصرف، تسوية الخزينة، الترحيل اليومي والشهري.
- **حسابات الأطباء والمرتبات**: تسوية حصص الأطباء (نسبة مئوية أو مبلغ ثابت للزيارة) وتسجيل مسيرات الرواتب والمكافآت والخصومات.
- **التقارير المالية المجمعة**: ملخصات فورية وتقارير الإيرادات والمصروفات وصافي الأرباح.
- **إدارة المستخدمين وسجل النشاط (Audit Log)**: صلاحيات تفصيلية لكل قسم مع حظر التصعيد التلقائي للصلاحيات.

## خطوات التشغيل والتطوير

1. تثبيت الاعتماديات:
   ```bash
   npm install
   ```
2. فحص السلامة النحوية وتشغيل الاختبارات:
   ```bash
   npm test
   ```
3. مراجعة دليل إعداد قاعدة البيانات في [SUPABASE_SETUP.md](SUPABASE_SETUP.md).

## ملاحظات الأمان والسرية

- هذا المستودع **خاص (Private)** ومملوك لمستشفى لجنة زكاة ميت على التخصصي.
- لا تضع مفاتيح سرية (`SUPABASE_SERVICE_ROLE_KEY` أو كلمات المرور) في الملفات العامة أو مستودعات Git.
